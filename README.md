# Abir - My AI Assistant

Personal AI Assistant with overlay support for Mobile Legends (and other games), study mode, and modular features.

## How to open in Android Studio
1. Clone this repo: `git clone https://github.com/abir-04/Abir.git`
2. Open the folder in Android Studio
3. Let it sync Gradle
4. Grant overlay permission on device when prompted
5. Run on Android 8.0+

## Features
See `docs/FEATURES.md` for the full checklist.

Most Android features have working code or clear skeletons. Real AI integration, Firebase, and the Windows companion are the main remaining pieces.
